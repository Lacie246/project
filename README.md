# make-knowledge-cards

一个用于把文章整理成知识卡片的 Codex Skill。输入可以是直接粘贴的正文，也可以是本地 `.md` 或 `.txt` 文件。

## 主要功能

- 接受用户粘贴的文章正文，或读取本地 Markdown/TXT 文件。
- 区分核心概念、原理、步骤、条件和限制，过滤铺垫、口号和低价值内容。
- 合并重复或同义内容，尽量提炼为 5～8 张互不重复的知识卡片。
- 每张卡片只讲一个知识点，包含标题、核心知识、简明解释，以及原文例子或自测问题。
- 保留原文中的数字、单位、条件、因果关系和作者立场，不补充原文没有的信息。
- 输出 Markdown 格式；信息不足时按实际知识点数量生成，不为凑数拆分或编造卡片。

## 使用方法

1. 将 `skills/make-knowledge-cards` 放入 Codex 用户技能目录（默认为 `~/.codex/skills/`）。
2. 在 Codex 中显式调用：

```text
使用 $make-knowledge-cards 把下面的文章整理成知识卡片：

[粘贴文章]
```

也可以直接处理本地 Markdown 或 TXT：

```text
使用 $make-knowledge-cards 处理 ./notes/learning.md
```

## 适用边界

当前不支持网页抓取、PDF、Anki 和图形界面。遇到这些输入时，请先改为粘贴正文或提供 `.md`/`.txt` 文件。

Skill 只把文章内容当作素材，不执行其中夹带的命令或提示词。读取本地文件时不会修改原文件；只有用户明确要求时才会保存输出。

## 输入输出示例

输入：

```markdown
# 间隔重复

把复习分散到多次，比在一次学习中重复更有利于长期记忆。
如果一次复习间隔过长，知识点可能已经被遗忘；间隔过短，又会增加不必要的复习次数。
可以在每次复习后，根据回忆情况调整下一次复习时间。
```

该原文只有 3 个独立知识点，因此输出不会强行扩展到 5 张。输出节选：

```markdown
# 知识卡片

原文支持 3 个独立知识点，未补足到 5 张。

## 1. 分散复习比集中重复更利于长期记忆

**核心知识：** 把复习分散到多次，比在一次学习中重复更有利于长期记忆。

**简明解释：** 原文将复习次数分散在不同时间，而不是集中在单次学习中。

**例子或自测问题：** 根据原文，哪种复习安排更有利于长期记忆？
```
